# ⚙️ Configuration

This section contains the actual configuration information for the homelab.

The other branches explain what the project is and how it will be built.

This branch is where we record the actual values we use.

For example:

- IP addresses
- VLAN IDs
- VM names
- VM resources
- Storage allocations
- Network interfaces
- Ports
- Hostnames
- Services
- Hardware assignments

The aim is to make the environment easy to understand and rebuild.

# ⚠️ Important

**Do not store passwords, API keys, private keys, tokens or other secrets in this repository.**
